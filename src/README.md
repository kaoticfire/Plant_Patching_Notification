# Plant_Patching_Notification 
A set of scripts to automate notifications for plant patching. List of recipients is contained in the pre-patch and the post patch scripts. The notification is logged for audit purposes. 

## Important Note 
The format for the logging of the notifications is contained in the yaml file.
